## 실행 환경과 범위

Python 3.10.20, torch 2.14.0, OpenCV 5.0.0, numpy 2.2.6, 로컬 Jazzy/Fast DDS. 에이전트 실행 환경에서 auto 장치는 CPU로 선택됨. MPS/CUDA 속도·호환성, 다른 OS 실제 설치, 전체 bag 모든 프레임의 차선 검출 정확도, 실제 차량 폐루프 주행은 이번에 검증하지 않음.

원본 PID 계산식을 재사용했지만 이 패키지의 PID는 카메라 처리 시점마다 계산합니다. 원본 drive_control의 독립 20Hz 모터 루프와 같은 실행 주기는 아닙니다. 기록된 피드백을 사용하므로 gain 변경이 실제 바퀴 응답을 바꾸지 않습니다.

테스트 출력은 로컬 `output/` 아래이며 git에서 제외합니다. 원본 bag은 변경하지 않았습니다. 프로젝트 전용 `.venv`에 Python 의존성을 설치했고 기존 ROS 빌드 가상환경에 새 패키지를 설치하지 않았습니다.
